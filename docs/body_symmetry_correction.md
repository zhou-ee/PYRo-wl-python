# 机体对称性与惯量导出误差修正

2026-10-09，用户确认机体质量分布前后、左右对称，原非零交叉惯量属于模型导出误差。机体坐标轴沿对称方向，动力学中的机体转动惯量取质心。

## 参数修正

统一入口 `src/wheel_leg_lqr/config.py` 的 `body_inertia` 改为对角矩阵：

```text
[[0.418395663, 0,           0],
 [0,           0.582892610, 0],
 [0,           0,           0.451416848]] kg·m²
```

移除 `Ixz=Izx=-0.0260436`；`Ixy/Iyx/Iyz/Izy` 原本为零。机体质量维持 18.9255 kg，三个对角惯量维持原值，质心前后/左右位置已为零。腿质心调度开关及其曲线单独控制，不属于机体惯量导出误差。

因为 `Ixz=-∫xz dm`，前后镜像的成对质量元使该项抵消；左右镜像消除 Ixy 和 Iyz。原库只检查左右对称，允许保留 Ixz，这不能完整表达用户明确的机体对称假设。

## 作用范围

地面模型读取统一惯量张量，修正作用于其质量矩阵、线性化、LQR 和基于地面模型的 RDOB。腾空模型从同一配置读取 Iyy；不额外硬编码交叉惯量。当前接触扩展原本没有机体完整转动惯量项，无需另行删除 Ixz。

不将整机质量矩阵或控制增益矩阵的非对角元素强制置零：非直立姿态、腿质心变化、关节相对运动以及不同方向对角惯量之间的正常动力学耦合仍需保留。三个对角惯量不要求相等。

固定数值回归样本 `tests/reference_parameters.py` 刻意保留修正前的非零 Ixz，并注明历史含义。这样修改生产配置不需要改写原数值期望，也可继续检查支持一般惯量张量的模型；当前配置的机体对称性由独立集成测试检查。

## 计算与导出

重新生成 Python 仓库内的活动产物，保留原网格设置：

```powershell
python -m wheel_leg_lqr.cli.ground_lqr --step 0.02
python -m wheel_leg_lqr.cli.airborne_lqr
python -m wheel_leg_lqr.cli.rdob --step 0.02
python -m wheel_leg_lqr.cli.rdob --mode node --output-dir outputs/rdob_node
```

地面输出为 `outputs/ground_lqr/lqr_coef.h`，腾空输出为 `outputs/airborne_lqr/airborne_lqr_coef.h`，RDOB 输出为 `outputs/rdob/rdob_schedule.h` 和 `outputs/rdob_node/rdob_coefficients.h`。各 JSON 保存修正后的参数快照与指纹。这些是 Python 仓库的生成物，未自动覆盖下位机源码中的系数头文件。

12 rad/s 分析脚本也重新读取配置运行。修正前的全精度结果保存为 `outputs/spin_trim_12/results_before_symmetry_fix.json`；当前结果保存为 `results.json`。关闭腿质心前后调度、机体直立、双腿等长、轮心中点不平移、恒速偏航时，旋转腿角为零，六路旋转惯性配平增量为零；摩擦及偏航启停力矩不在这个计算中。
