# 单腿下 0.18 m 台阶：跌落与冲击筛查

## 场景

机器人开始于等高双支撑面，两个实际腿长均为 \(0.28\ \mathrm{m}\)。腿 1 越过台阶边缘后失去上台阶接触；腿 2 保留在高台阶上，低台阶低 \(0.18\ \mathrm{m}\)。

为使重新建立双支撑后的平均腿长仍为 \(0.28\ \mathrm{m}\)，几何求解得到：

\[
(L_1,L_2)=(0.369927,\ 0.190073)\ \mathrm{m}.
\]

写成平均和差动腿长：

\[
\bar L=\frac{L_1+L_2}{2}=0.28\ \mathrm{m},\qquad
L_d=\frac{L_1-L_2}{2}=0.089927\ \mathrm{m}.
\]

两条腿距工作域 \([0.18,0.38]\ \mathrm{m}\) 的边界各仅约 \(10.1\ \mathrm{mm}\)。

## 混合接触模型

静态七坐标模型将左右地面高差 \(\kappa_g\) 作为固定参数，无法描述单轮脱离。筛查模型增加相对轮高和轮轴中点世界高度：

\[
q_{\mathrm{drop}}=
[x,\psi,\theta,\phi,\bar l,\beta_1,\beta_2,\kappa,z_C]^T.
\]

下降轮和机械行程上下限都用单侧弹簧-阻尼器接触：

\[
f_n=\max(0,-k_g\,g-c_g\,\dot g),\qquad
f_{\mathrm{stop}}=\max(0,-k_s\,g_s-c_s\,\dot g_s).
\]

默认采用 5 kN/m、200 N s/m 的地面法向参数，以及 10 kN/m、300 N s/m 的腿长机械限位参数；每个 1 kHz 控制周期用五个动力学子步积分。控制仍使用完整 14 状态 LQR、Tw+FL RDOB 补偿和实际限幅后的输入。

模型保留配置相关的 \(M(q)\)、\(g(q)\)、\(S(q)\)、垂直接触、限位接触、接触切换、LQR、RDOB 和输入限幅。它不包含轮缘几何、水平摩擦、执行器带宽、状态估计延迟，并延续源静态模型没有速度二次项的约定。接触刚度和阻尼尚未由实物辨识，因此接触力和冲量只表示当前参数假设下的趋势。

## 结果

运行：

~~~powershell
wheelleg-step-drop --step-height 0.18 --down-leg 0 --horizon 3.0
~~~

默认以机械上下限接触约束 \(L_i\in[0.18,0.38]\ \mathrm{m}\) 继续积分。结果：

| 指标 | 数值 |
|---|---:|
| 下降腿触及低台阶 | \(t=90.27\ \mathrm{ms}\) |
| 触地前轮竖直速度 | \(-2.0542\ \mathrm{m/s}\) |
| 限位与触地后数值发散 | \(t=127.0\ \mathrm{ms}\) |
| 触发限幅周期数 | 124 |
| 收敛 | 否 |

下降侧先撞击 \(0.38\ \mathrm{m}\) 上限，随后触地；仿真在 127 ms 时已离开当前非线性接触模型的数值包络。机械限位使过程可继续到触地，但没有使闭环恢复稳定。

完整 LQR 中的横滚反馈也参与了该过程。50 ms 时，横滚项对两侧 \(F_L\) 的分量约为 \((-27.69,+27.95)\ \mathrm{N}\)，它确实主动差动分配腿力；同时平均腿长项约为 \((-37.90,-36.99)\ \mathrm{N}\)，RDOB 补偿约为 \((-55.78,-49.78)\ \mathrm{N}\)，俯仰力矩通道已经限幅。因此结论不是缺少横滚辅助，而是固定双支撑 LQR/RDOB 在单支撑接触拓扑下无法同时维持差动腿长、姿态和行程约束。

以相同接触参数进行的补偿方案对比也都未收敛：

| 补偿通道 | 触地前轮竖直速度 | 终止时刻 | 收敛 |
|---|---:|---:|---|
| 关闭 RDOB 补偿 | \(-2.3343\ \mathrm{m/s}\) | 167 ms | 否 |
| Tw+FL | \(-2.0542\ \mathrm{m/s}\) | 127 ms | 否 |
| 全六通道 | \(-4.7318\ \mathrm{m/s}\) | 132 ms | 否 |

Tw+FL 给出了三种方案中最低的触地前速度和最低的接触冲击趋势，但仍无法抵消单支撑拓扑变化和机械限位带来的大残差。

## 工程动作

下台阶需要由接触状态机显式控制平均和差动腿长：

\[
L_1^\star=\bar L^\star+\sigma L_d^\star,\qquad
L_2^\star=\bar L^\star-\sigma L_d^\star,
\]

其中 \(\sigma=+1\) 表示腿 1 下台阶，\(\sigma=-1\) 表示腿 2 下台阶。

1. 在下降轮离开边缘前的双支撑阶段，平滑预置差动长度到接近 \((0.36993,0.19007)\ \mathrm{m}\)，并检查速度、加速度、力矩和法向力裕度。
2. 为每条腿分别限制长度和伸缩速度，到达上、下限时切换保护动作。
3. 在单支撑及接触判定不确定期间，门控 RDOB 补偿或显著降低补偿带宽。
4. 触地确认后，按新 \(L_1,L_2\) 调度 LQR/RDOB，并用测得速度误差重置 \(z=\hat d_u-\Gamma\delta\dot q\)。
5. 用实测轮胎、地面、机械限位刚度和阻尼标定接触模型，再评估实机峰值法向力。
